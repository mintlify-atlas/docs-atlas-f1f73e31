---
title: "Get started with GymGuard"
description: "Install GymGuard on Python 3.11+, configure PyTorch with CUDA, and launch your first live webcam pose-analysis session in five steps."
---

GymGuard runs a FastAPI backend that streams live pose analysis to your browser over WebSockets. The setup below gets you from a fresh clone to a running session in about five minutes, assuming you have an NVIDIA GPU and Python 3.11+ installed.

<Steps>
  <Step title="Clone the repo">
    ```bash
    git clone https://github.com/12somyasahu/GymGuard.git && cd GymGuard
    ```
  </Step>

  <Step title="Create a virtual environment">
    ```bash
    python -m venv venv
    ```

    Then activate it:

    <Tabs>
      <Tab title="Windows">
        ```bash
        venv\Scripts\activate
        ```
      </Tab>
      <Tab title="Linux / Mac">
        ```bash
        source venv/bin/activate
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Install PyTorch with CUDA">
    Run this command before installing `requirements.txt`. PyTorch must be installed with the CUDA index URL to enable GPU support.

    ```bash
    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
    ```

    Then verify that your GPU is visible:

    ```bash
    python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
    ```

    You should see `True` followed by your GPU name, for example `True NVIDIA GeForce RTX 3060`.
  </Step>

  <Step title="Install remaining dependencies">
    ```bash
    pip install -r requirements.txt
    ```
  </Step>

  <Step title="Start GymGuard">
    ```bash
    python main.py
    ```

    Once the server is running, open your browser and go to **http://localhost:8000**.

    <Warning>
      Do NOT open `static/index.html` directly from the file system. The frontend relies on the FastAPI backend and WebSocket connection. Always access GymGuard through **http://localhost:8000**.
    </Warning>

    <Note>
      On first run, Ultralytics automatically downloads `yolov8m-pose.pt` (~50 MB). This happens once and is cached for future runs.
    </Note>
  </Step>
</Steps>
